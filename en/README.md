# Rakszawa, Wisconsin -- English edition

Source chapters for the English edition. One markdown file per chapter;
`.clean.md` files are the ASCII-normalised build inputs.

The English edition is deliberately **ASCII-only**. Polish quotations appear
transliterated (`Poniewierac ma, a nie smakowac`); the Polish edition restores
the correct diacritics.
