# Rakszawa, Wisconsin -- wydanie polskie

Rozdzialy zrodlowe wydania polskiego. Jeden plik markdown na rozdzial; pliki
`.clean.md` sluza do zlozenia ksiazki.

To wydanie nie tlumaczy polskiego na polski. Glosy objasniajace polskie slowa
cudzoziemcom zostaly usuniete; zostaly etymologie, hasla ze slownika PAN i daty
-- czyli to, co jest ciekawe takze dla polskiego czytelnika. Dlatego wersja
polska jest krotsza od angielskiej przy identycznej liczbie akapitow.
